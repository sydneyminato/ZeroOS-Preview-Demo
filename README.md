これは、ZeroOS（開発中のOSプロジェクト）が目指す操作感を体験できる**プレビュー版デモ**です。

macOS上で動くネイティブアプリとして、以下を体験できます。

- **VSS Desktop** — アイコンをドラッグ&ドロップで整理できる、簡易的な仮想デスクトップ
- **IIRE (統合中間表現環境)** — 作りたいアプリを日本語で伝えると、AIがその場でコードを生成し、実際に動くアプリとしてデプロイする様子

> ⚠️ このデモは、今お使いのMac（macOS）の上で動く「体験版アプリ」です。ZeroOSは、WindowsやmacOSと同じ種類の、新しく開発中のOS（パソコンを直接動かす基本ソフト）です。今回のデモは、そのZeroOSが完成したときにどんな操作感になるかを、一足先に体験してもらうためのものです。今お使いのMac自体がZeroOSに置き換わるわけではなく、ZeroOS本体もまだこのデモの中には入っていません。

---

## 動作環境

- **macOS**（**Apple Silicon Mac（M1・M2・M3・M4など）専用**です。Intel Macでは現時点で動作しません）
  - チップの種類は、Appleメニュー→「このMacについて」の「チップ」欄で確認できます（「Apple M○」と書いてあればApple Silicon）
- インターネット接続（IIREでのアプリ生成に必要です）
- Google Geminiの無料APIキー（お持ちでない場合は後述の手順で取得できます）

## ダウンロードと起動方法

### 1. ダウンロード

[Releases](../../releases) から最新版の zip ファイルをダウンロードし、展開してください。

### 2. 初回起動時の注意（Gatekeeperの警告について）

このアプリは Apple の有料デベロッパー登録による署名・公証を行っていません。そのため、初めて起動しようとすると

> "○○" は開発元を確認できないため開けません

という警告が表示されます。これは悪意のあるソフトという意味ではなく、**個人開発のアプリに毎回表示される標準的な警告**です。以下のどちらかの方法で開けます。

**方法A（推奨）:** 展開したフォルダの中にある実行ファイル（`zig-out/bin/` 以下の `vss_desktop` や `zero_browser`）を **Controlキーを押しながらクリック**（または右クリック）→「開く」を選択 → 表示されるダイアログで再度「開く」を選択。これを `vss_desktop` と `zero_browser` の両方に対して、最初の1回だけ行ってください。

**方法B:** ターミナルで、展開したフォルダに対して以下を実行してください。
```
xattr -cr "展開したフォルダのパス"
```

### 3. 起動

ターミナルを開き、展開したフォルダに移動してから：

```
cd 展開したフォルダのパス
chmod +x start_zeroos.sh
./start_zeroos.sh
```

これだけで、VSSデスクトップの画面が自動的に開きます。（内部でサーバーとデスクトップアプリの2つを起動していますが、この1コマンドだけで完結します。）

終了するときは、デスクトップのウィンドウを閉じるか、ターミナルで `Ctrl+C` を押してください。

## 使い方

### VSS Desktop

- アイコンをダブルクリックするとフォルダの中身を開けます
- アイコンをドラッグ&ドロップで、フォルダや「📥 待機箱」に移動できます
- Shift（またはCmd）を押しながらクリックすると、複数のアイコンをまとめて選択・移動できます
- 「➕ 新規アペンド」から、新しいアイテムを追加できます

### ⚡ IIRE（AIによるアプリ生成）

1. デスクトップの「⚡ IIRE」ボタンをクリック
2. 画面右上の「Gemini API Key」欄に、お持ちのAPIキーを入力してください
   - お持ちでない場合は、隣の「[取得]」リンクから [Google AI Studio](https://aistudio.google.com/app/apikey) で無料発行できます
   - 入力したキーはこの端末の中だけで使われ、Google以外には送信されません
3. 「作りたいアプリを日本語で自然に入力」欄に、作りたいものを入力（例：「シンプルな電卓」「デジタル時計」など）
4. 「✨ 生成＆デプロイ」を押すと、その場でコードが生成され、右側のプレビューで実際に動作します
5. 気に入ったアプリは「💾 保存」で保存でき、左下のプルダウンからいつでも呼び出せます

## 既知の制限事項

- 内蔵ブラウザ（ZeroBrowser）は、見出し・段落・リンク・画像・フォームの表示に対応していますが、JavaScriptを使った動的なWebページの再現には対応していません（IIREで生成したアプリ自体は別の仕組みで動くため、この制限を受けません）
- IIREでのアプリ生成には、その都度インターネット接続とGemini APIの利用が必要です
- プレビュー版のため、予期しない動作が発生する場合があります

## トラブルシューティング

**デスクトップにアイコンが表示されない**
`./start_zeroos.sh` を実行したターミナルをまだ開いたままにしているか確認してください。閉じてしまった場合は、もう一度実行し直してください。

**起動時に「zero_browser が見つかりません」と表示される**
`zig-out/bin/` フォルダの中に `zero_browser` が入っているか確認してください。フォルダの中身が壊れている可能性があります。ダウンロードし直すことをお勧めします。

**それでも解決しない場合**
一度すべてのウィンドウ・ターミナルを閉じてから、改めて `./start_zeroos.sh` を実行してみてください。
